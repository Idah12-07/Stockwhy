# H-MEM reference implementation (vendored)

Copied unchanged from https://github.com/Meterless/Meterless (engines/hmem/reference/src), Apache License 2.0.
It is Meterless's open-source hierarchical memory engine: memories are captured, ranked on retrieval, and every
change is written to an append-only trust ledger. StockWhy uses it as the agents' shared case memory.
